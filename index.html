Teachers Pet is a desktop AI workspace designed to help one user work across documents, planning, research, communication, and connected services from a single interface. Google features are optional and require the user to explicitly authorize access through Google OAuth.

USER-AUTHORIZED INTEGRATIONS

AI Workspace

A unified desktop environment for AI-assisted writing, research, coding, planning, and creative work.

Google Integration

Optional access to Google services is used only after authorization and only to perform features the user invokes.

User Control

Connected accounts can be disconnected through Google account controls. The application is designed around user-directed actions rather than advertising or data brokerage.

About Google data access

Teachers Pet requests Google permissions only to provide user-facing features that interact with the Google services the user chooses to connect. See the Privacy Policy for details about access, storage, sharing, and deletion.
