Privacy Policy

Effective: October 7, 2026

Teachers Pet is a user-controlled desktop application. Google account access is optional and is activated only when the user chooses to connect a Google account.

Information the application may access

Depending on features enabled by the user and permissions granted through Google OAuth, Teachers Pet may access Google account profile information and data from services such as Gmail, Google Drive, Docs, Sheets, Slides, Calendar, Tasks, Contacts, Classroom, YouTube, and other Google services shown on the authorization screen.

How Google user data is used

Google user data is used only to provide or improve user-facing functionality requested by the user, such as reading or creating documents, finding files, managing calendar items, assisting with email, or completing another action the user initiates. Teachers Pet does not sell Google user data and does not use Google user data for advertising.

AI-assisted features and third-party processing

When the user explicitly invokes an AI-assisted feature, content supplied to that feature may be sent to the AI provider configured for that request when necessary to produce the requested result. The application does not use Google user data to build advertising profiles. Users should review the terms and privacy practices of any model provider they configure.

Storage and security

OAuth credentials and application state may be stored on the device running Teachers Pet so the user can remain signed in and use connected features. The application may also use user-configured cloud services for application data and continuity. Access is limited to the scopes the user authorizes. No public website page contains OAuth tokens, API keys, or account passwords.

Sharing

Teachers Pet does not sell Google user data. Data is shared only as needed to carry out a user-requested function, with service providers necessary to operate that function, when required by law, or when the user explicitly directs the application to share it.

Retention and deletion

Users can revoke Teachers Pet's Google access at any time from their Google Account's third-party access settings. Local application data and cached account information can be removed by deleting the application's local data. Requests for assistance with data deletion can be made through the support page.

Google API Services User Data Policy

Teachers Pet's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements where applicable.

Changes

This policy may be updated as Teachers Pet features change. Material changes will be reflected on this page with a new effective date.

Contact

For privacy or data-deletion questions, use the contact method on the Support page.
